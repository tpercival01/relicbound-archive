# Relicbound Archive

The official companion website for Relicbound, an iPhone walking collection game.

Relicbound suggests nearby walking expeditions, tracks completed routes and rewards players with sealed cases containing relics from four lost civilisations.

## Website

Planned address:

`https://relicbound.thomaspercival.dev`

The website will provide:

- Product landing page
- How Relicbound works
- Searchable archive of 105 relics
- Four civilisation collections
- Individual relic lore pages
- TestFlight and App Store links
- Privacy policy
- Support information
- Press resources

## Technology

- Astro
- TypeScript
- Static site generation
- GitHub Pages
- GitHub Actions
- No backend
- No accounts
- No personal player data

## Content

The launch archive covers:

- The Tideborn
- The Emberwright Dominion
- The Verdant Choir
- The Meridian Archive

Relic data will be maintained in a canonical structured dataset shared with the iOS application.
